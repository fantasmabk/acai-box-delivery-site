Política de Privacidade

Última atualização: 17/09/2026

1. Quem trata seus dados

FR NEGÓCIOS DIGITAIS LTDA (CNPJ 57.413.268/0001-72) é a controladora dos dados pessoais coletados neste site, nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018).

2. Quais dados coletamos

Para processar seu pedido, coletamos:

  • Nome completo, e-mail e CPF (necessário para geração da cobrança Pix)
  • WhatsApp (opcional, usado apenas para contato sobre o pedido)
  • Endereço de entrega
  • Se você criar uma conta: senha (armazenada de forma criptografada, nunca em texto puro)

3. Para que usamos seus dados

Usamos seus dados exclusivamente para processar e entregar seu pedido, gerar a cobrança Pix junto ao nosso provedor de pagamentos, e (caso você autorize) enviar comunicações de marketing. Não vendemos seus dados a terceiros.

4. Com quem compartilhamos

Compartilhamos dados de pagamento (nome, e-mail, CPF, valor) com o provedor de pagamentos Pix que processa a cobrança, exclusivamente para viabilizar a transação. Usamos também o Google Ads/Google Tag Manager para medir a eficácia de nossas campanhas de anúncios.

5. Seus direitos

Você pode solicitar a qualquer momento a exclusão, correção ou exportação dos seus dados, escrevendo para frnegociosdigitaisltda@gmail.com.
